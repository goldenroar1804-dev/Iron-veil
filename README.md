# IRON VEIL

Native Meta Quest tactical PvE prototype built with Godot 4 and OpenXR.

## Current features
- OpenXR head and controller tracking.
- Smooth thumbstick locomotion and turning with standing-capsule collision checks.
- Right-hand grip pickup/drop for the M4 training prop; trigger firing and haptic feedback.
- Articulated controller-following glove hands. Grip curls all four fingers and the thumb; trigger curls the index finger.
- Grip interaction on nearby doors. Doors swing open/closed with animated collision and haptic feedback.
- Imported two-storey suburban house and sedan GLB assets, with authored CQB collision shells and interior stair/upper-floor geometry.
- House cutaway rendering intended to reveal the playable interior from the street; roof and front-facade panels are hidden when the GLB separates them into individual meshes.
- Fences, foliage, streetlights, and human-shaped CQB targets use shaped geometry rather than single solid blocks.
- Imported GLB materials retain their authored PBR surfaces and receive a subtle detail-texture layer.
- CC0 rifle-shot and concrete-footstep audio are downloaded and cached on first launch.

## Bundled 3D assets
- `assets/models/environment/suburban_house.glb` — detailed two-storey house.
- `assets/models/environment/sedan.glb` — detailed sedan.
- `assets/models/weapons/m4_carbine.glb` — rounded, smoothed, PBR M4-style training prop generated by `tools/build_weapon_model.py`.
- `assets/models/hands/left_hand.glb` and `right_hand.glb` — static glove references. Runtime hands are built separately from articulated meshes so grip and trigger input can animate the fingers.

The GitHub Actions workflow `.github/workflows/import-cc0-assets.yml` downloads the house/sedan assets, generates the rifle and hand GLBs, validates them, and commits updated files.

## Controls
- Left thumbstick: move.
- Right thumbstick: turn.
- Right grip: pick up/drop the rifle when close to its stand; grip near a door toggles it open/closed.
- Left or right grip: curl the corresponding hand; grip near a door toggles it.
- Right trigger: fire when holding the rifle; trigger also curls the index finger.

## Open the project on Quest 3
1. Download the repository ZIP from GitHub and extract it.
2. Import the folder into Godot 4.6 with OpenXR enabled.
3. Run the project on the headset.

## Testing status
Repository changes and the GLB-generation workflow have been checked. Godot editor import, static GDScript parsing, APK export, and physical Quest 3 testing have not been run in this environment. Please verify the imported house's exact cutaway panels, weapon scale/hand alignment, and door collision in-headset; the house cutaway helper only hides front/roof panels when the GLB exposes those panels as separate mesh nodes.
