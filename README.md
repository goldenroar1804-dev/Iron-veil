# IRON VEIL

Native Meta Quest tactical PvE prototype built with Godot 4 and OpenXR.

## Current milestone
- Minimal OpenXR scene structure
- XROrigin3D and XRCamera3D
- Left/right XR controller tracking markers
- Lightweight greybox training range
- Compatibility renderer selected for an initial mobile-focused test

## Open the project on Quest 3
1. Install **Godot XR Editor** from the Meta Horizon Store, or use the official Android download page.
2. Download this repository as a ZIP from GitHub and extract it with a Quest file manager.
3. In Godot XR Editor, import the extracted folder as a project.
4. Confirm OpenXR is enabled in Project Settings and run the project.

The first goal is to verify that the scene launches correctly in the headset. APK export and the required Android build environment are a separate step.

## Roadmap
1. Verify OpenXR startup on Quest 3.
2. Add smooth locomotion and smooth turning.

4. Add detachable magazines and a physical reload sequence.
5. Add a PvE enemy AI sandbox and mission objectives.
